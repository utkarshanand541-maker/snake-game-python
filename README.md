# 🐍 Snake Game (Python)

A classic Snake Game built using Python and Pygame.

## 🚀 Features

* Real-time snake movement
* Collision detection
* Score tracking system

## 🛠️ Tech Stack

* Python
* Pygame

## ▶️ How to Run

pip install pygame
python main.py
